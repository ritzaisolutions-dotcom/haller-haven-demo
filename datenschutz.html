2. Hosting (Vercel)

Die Website liegt bei Vercel Inc., USA, inkl. Serverless-Funktionen unter /api/*. Logs: IP, URL, Zeitpunkt, User-Agent. AVV/DPA abgeschlossen. Drittland: EU-US Data Privacy Framework bzw. Standardvertragsklauseln, soweit einschlägig.

3. Formulare (EU-Mail)

Kontakt, Objektanfrage, Bewertung und Suchprofil sendet der Browser an POST /api/inquiries auf Vercel. Der Server verschickt eine E-Mail per SMTP an ein Postfach in der EU (Demo: konfiguriertes Inquiry-Postfach). Es wird kein Web3Forms und kein Versand in Drittländer über Formular-SaaS genutzt.

Pflicht: Name, E-Mail, Telefon, Einwilligungs-Checkbox. Objektformular zusätzlich: Finanzierung, Eigenkapital, Nutzung, Einzugszeitraum. Rechtsgrundlage: Art. 6 Abs. 1 lit. a DSGVO; ergänzend lit. b bei vorvertraglicher Anfrage.

Zusätzlich schreibt der Server bei Erfolg Anfragezähler in Supabase (EU Frankfurt), ohne den Nachrichteninhalt.

4. Cal.com

Nach einer erfolgreichen Anfrage kann ein Buchungsfenster (iframe) zu Cal.com erscheinen, sofern eine öffentliche Event-URL gesetzt ist. Dann gelten zusätzlich die Hinweise von Cal.com. Ohne URL erscheint nur ein Rückruf-Hinweis — kein Dritt-Embed.

5. Supabase

Objektliste, Uploads (Bucket listing-images), Consent-Log, Rate-Limits. Region EU (Frankfurt). AVV abgeschlossen.

6. Kein Consent-Manager

Diese Website setzt kein Analyse-Tracking, keine Marketing-Pixel und keinen Consent-Manager. Es gibt keinen Cookie-Banner, weil keine nicht-notwendigen Tracking-Cookies gesetzt werden.

7. Technisch notwendige Speicherung

  • rais_admin — nur nach Login auf /admin, Sitzung rund 8 Stunden, für den Objekteditor.
  • Finanzierungsrechner — optionale Werte im Browser (localStorage), ohne Profilbildung.
  • Hosting-Logs bei Vercel (IP, URL, Zeitpunkt, User-Agent) — Betrieb und Sicherheit, keine Reichweitenmessung.

Formular-Einwilligungen (Checkbox) bleiben die Rechtsgrundlage für Anfragen. Cal.com wird nur nach erfolgreichem Absenden als iframe geladen, sofern eine Event-URL gesetzt ist.
